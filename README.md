# AI Powered Timetable Scheduler

A modern, intelligent timetable scheduling application designed for educational institutions. This application helps manage timetables, teacher substitutions, and organizational scheduling with an AI-powered approach.

## Features

- **AI-Powered Timetable Generation**: Create optimized timetables automatically using intelligent algorithms
- **Teacher Substitute Management**: Handle teacher absences and substitutions efficiently
- **User Management**: Invite and manage team members within your organization
- **Interactive Dashboard**: Clean, modern interface with easy navigation
- **Responsive Design**: Works seamlessly on desktop, tablet, and mobile devices
- **Step-by-Step Guide**: Built-in tutorials to help users get started
- **Demo Scheduling**: Book personalized walkthroughs

## Technologies Used

- HTML5
- CSS3 (with modern gradients and animations)
- JavaScript (Vanilla JS)
- Font Awesome Icons

## Getting Started

1. Clone or download this repository
2. Open `index.html` in your web browser
3. Start exploring the features!

## File Structure

```
├── index.html          # Main HTML file
├── styles.css          # Styling and responsive design

└── README.md          # Documentation
```

## Features Overview

### Dashboard Cards

1. **Generate Timetable** - Create new timetables with AI assistance
2. **Teacher Substitute** - Manage teacher absences and find substitutes
3. **Step-by-Step Guide** - Learn how to use the platform
4. **Schedule Demo** - Book a personalized walkthrough
5. **Invite Users** - Add team members to your organization
6. **Manage Users** - View and manage organization members

### User Interface

- Clean, modern design with gradient cards
- Smooth animations and transitions
- Interactive notifications
- Modal forms for data entry
- Responsive layout for all screen sizes

## Customization
